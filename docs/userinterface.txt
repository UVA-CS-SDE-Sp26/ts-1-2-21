Documentation for User Interface feature of TopSecret project

Responsible for command-line arguments

Returns number of command line args @index 0, file number to read @index 1, and cipher number to use @index 2

Cases:

no args: java TopSecret
--list numbered files available to display

one arg: java TopSecret file1
--display contents of file1 to screen, use default key to decrypt

two args: java TopSecret file1 cipher2
--display contents of file1 to screen, use cipher2 key to decrypt
