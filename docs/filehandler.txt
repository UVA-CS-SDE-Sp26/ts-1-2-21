FileHandler Class and Tests

The `FileHandler` class is a utility class that provides basic
file handling abilities, including listing files in a specified directory
and reading the contents of a specific file by index. This class operates
on files stored in a `data` directory.

FileHandler Class Methods

`listFiles()`
This method retrieves a list of file names from the `data` directory and returns them as a `List<String>`.
If the directory contains files, their names are added to the list; otherwise, an empty list is returned.

public List<String> listFiles()
method reads the contents of a specific file from the `data` directory based on the given file number.
The method attempts to load the content of the file and returns it as a string. If there is an error or if the file number
is invalid, it returns an error message.
